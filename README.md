# FOP Attendance CRM

A professional admin portal for managing choir and musician attendance, contacts, and multi-date reporting.

## Stack
- Next.js
- Supabase
- Vercel
- Tailwind CSS

## Getting started
1. Install dependencies:
   npm install
2. Copy `.env.example` to `.env.local` and populate your Supabase values.
3. Start the app:
   npm run dev
4. Open http://localhost:3000

## Main features
- Secure admin access flow
- Contact directory management
- Quick attendance check-in screen
- QR-assisted and manual attendance capture
- Date-range attendance reports
- CSV/XLSX import-ready workflow

## Role model
- Super admin: full access and reporting
- Admin: attendance and contact management without reporting access
